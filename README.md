# 출결바로 설치 파일

중·고등학교 담임과 교과 교사를 위한 Windows 출결 정리 프로그램입니다.

**[에듀잇티에서 받기](https://eduitit.com/downloads/chulgyeol/)**

- `Chulgyeol-setup-*.exe`: 설치형. 설치할 수 있는 PC에서 권장합니다.
- `Chulgyeol-portable-*.exe`: 설치가 어려운 학교 PC용 무설치판입니다.
- `latest.yml`과 `.blockmap`: 설치형 자동 업데이트에 사용하는 파일입니다.

개인 개발자 앱으로 코드 서명이 없습니다. 처음 실행할 때 Windows 보호 경고가 나타날 수 있습니다.

이 저장소에는 설치 파일과 배포 확인 절차만 보관합니다. 앱 소스는 비공개 저장소에서 관리합니다.
